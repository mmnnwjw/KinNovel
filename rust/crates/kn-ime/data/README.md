# Pinyin dictionary

`pinyin.br` is generated by `tools/gen_pinyin.py` from
[rime-pinyin-simp](https://github.com/rime/rime-pinyin-simp) `pinyin_simp.dict.yaml`
(commit `0c6861e`, 2024-12-29), which is derived from the Android Open Source Project's
PinyinIME. Both are licensed under the Apache License 2.0 (copy in
`LICENSE-rime-pinyin-simp`). KOReader's pinyin keyboard uses the same source.

Format after Brotli decompression: UTF-8 text, one entry per line,
`<syllables joined by '>\t<word>\t<weight>`, sorted by key (bytewise) then weight
(descending).

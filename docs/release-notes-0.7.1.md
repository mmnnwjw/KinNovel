修复阅读历史/最近偶发闪退，图片按可见优先级加载并缓解偶发加载困难。

### 变更

- **图片优先级**：图片调度改为优先队列，当前页与全屏预览为最高优先级（0），相邻页预取为 3/6；从后面翻回某页时该页插图立即插队，不再排在预取任务之后。
- **失败自动重试**：失败图片按 2s、4s、8s… 退避自动重试，不再依赖用户再次翻页触发。
- **闲置重连**：连接闲置超过 20 秒主动重连，避免在服务端已按 `ClientTimeoutInterval` 关闭的 socket 上等满超时；Hub 调用超时从 60 秒收紧到 25 秒。
- **关于页**：补上 FBInk 参考项目条目。

### 修复

- **阅读历史闪退**：服务端对已删除书籍会在 `GetBookListByIds` 返回 `null` 元素，旧代码对 `None` 调用 `.get()` 抛异常，错误弹窗又重绘同一个破损页面，异常最终冲出输入循环导致应用退出。现在列表接口统一过滤非 `dict` 元素。
- **历史加载不出内容**：`GetBookListByIds` 对小说必须省略 `Type`（Web 端只在取漫画系列时传 `Type=Comic`），此前传 `Type=Novel` 会让服务端返回空列表。
- **渲染兜底**：页面渲染失败降级为错误页，单个手势处理异常不再终止输入循环。
- **加载失败重试**：阅读历史加入代际校验与显式「重试」按钮，失败后不再一直停在加载态。
- **裸数组返回**：`GetRank` 等服务端的裸数组返回同样做空值归一化。

## 安装

1. 下载 `KinNovel-v0.7.1.zip`。
2. 解压后把 `KinNovel` 目录复制到 `/mnt/us/extensions/kinnovel`。
3. 在 `/mnt/us/extensions/kinnovel/bin/config.json` 中填写 `account_email` 和 `account_password`。
4. 从 KUAL 进入 `KinNovel` 并启动。

完整配置和排障说明见 README.md。

修复阅读历史/最近偶发闪退，图片按可见优先级加载，并缓解偶发加载困难。

### 阅读历史 / 最近 / 排行榜

- **修复闪退根因**：服务端对已删除或失效的书籍会在 `GetBookListByIds` 返回 `null` 元素。旧代码在 `history.render()` 里直接对 `None` 调用 `.get()`，抛异常后又用错误弹窗重绘同一个破损页面，异常最终冲出输入循环导致应用退出。现在所有列表接口统一过滤非 `dict` 元素，页面渲染失败会降级为错误页，单个手势处理异常不再终止输入循环。
- **修复历史实际加载不出内容**：`GetBookListByIds` 对小说必须**省略** `Type`（Web 端只在取漫画系列时传 `Type=Comic`）。此前传 `Type=Novel` 会让服务端返回空列表，现在与 Web 端一致。
- 阅读历史新增 `generation` 代际校验与显式「重试」按钮，失败不再只弹一次窗后一直停在加载态。
- `GetRank` 等服务端的**裸数组**返回也做了同样的空值归一化。

### 图片加载优先级

- **当前页优先**：图片调度由先入先出改为优先队列。当前页与全屏预览为最高优先级（0），相邻页预取为 3/6。从后面翻回某页时，该页插图会立刻插队，不再排在此前的预取任务之后。
- **失败自动重试**：失败图片按 2s、4s、8s… 退避自动重试，不再依赖用户再次翻页；失败本身也不再触发「重绘→重新请求」的循环。
- 更长的退避会在后台静默进行，可见图片仍保持高优先级重试。

### 网络

- **缓解偶发加载困难**：连接闲置超过 20 秒后主动重连，避免在服务端已按 `ClientTimeoutInterval` 关闭的 socket 上等到超时。
- Hub 调用超时从 60 秒收紧到 25 秒，失败后仍会重连重试一次。

### 其它

- 「关于」页补上 **FBInk** 参考项目条目。
- 新增 `tools/live_page_probe.py`：用真实 API 数据离线渲染历史/最近/排行，验证空值不再导致崩溃。

### 测试

- Kindle 实机（Python 3.14）运行 **113 项单元测试全部通过**（1 项跳过）。
- 在线探测：阅读历史返回 24 个 ID，其中 1 个已失效为 `null`，过滤后 23 本正常渲染；最近 8 本、排行榜 48 条正常渲染。
- 实测应用启动至「正在监听触摸输入」无异常，`SIGTERM` 后 2 秒干净退出并恢复原屏。

## 安装

1. 下载 `KinNovel-v0.7.1.zip`。
2. 解压后把 `KinNovel` 目录复制到 `/mnt/us/extensions/kinnovel`。
3. 在 `/mnt/us/extensions/kinnovel/bin/config.json` 中填写 `account_email` 和 `account_password`。
4. 从 KUAL 进入 `KinNovel` 并启动。

完整配置和排障说明见 README.md。

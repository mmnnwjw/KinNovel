## 改进

- **更新更快更稳**：版本信息和安装包改从 KinNovel 自己的更新服务器获取，国内网络也能直连，不再依赖第三方 GitHub 加速镜像；GitHub 作为备用。在 Kindle Paperwhite 5 上下载安装包从约 30 秒缩短到约 13 秒。安装包下载后照常校验 SHA-256。

在 Kindle Paperwhite 5 上测试过。

## 安装

1.6.2 可以在「我的 → 关于」或 KUAL「KinNovel 工具箱 → 检查更新」里直接更新。1.6.1 及更早的版本需要手动安装这一次：下载 `KinNovel-v1.6.3.zip`，把其中 `KinNovel` 文件夹里的全部内容复制到 Kindle 的 `extensions/kinnovel/`，直接覆盖即可，账号、设置、进度、书签和缓存都会保留。

卸载：KUAL「KinNovel 工具箱 → 卸载 KinNovel」，或删除 `extensions/kinnovel/` 文件夹。

## 新功能

- **书签**：阅读时打开菜单，点顶栏的书签按钮就能给当前页加书签，有书签的页右上角会显示角标。阅读页里的「目录」变成了「目录与书签」，可以在这里跳到书签位置，长按可删除。改字号后书签位置依然准确。
- **章内跳页**：拖动或点按菜单里的进度条，可以跳到本章任意一页。在目录里换章或跳书签，都在原来的阅读页里完成，返回时不会多出几层页面。
- **书架文件夹与编辑**：云端书架可以点进文件夹浏览。长按书籍可移出书架，长按文件夹可删除它（里面的书移到上一层），两者都会先确认。书籍详情页新增「加入书架 / 移出书架」。
- **阅读统计**：「我的 → 阅读统计」显示今天、近 7 天和累计的阅读时长与页数、连续阅读天数、近 14 天的柱状图和读得最多的书。统计只保存在本机。
- **存储空间**：「我的 → 存储空间」显示章节、字体、插图和漫画缓存各占多少空间，可以分别清理或全部清理。阅读进度、书签、登录状态和设置不受影响。
- **休眠显示封面**（可选）：在「设置 → 显示」中打开，重启 KinNovel 后生效。休眠时会显示正在读的书的封面。有广告的机型仍使用系统屏保。
- **检查更新**：每天最多检查一次 GitHub 上的新版本，有更新时「关于」一栏会提示，不会自动安装。可在设置中关闭。
- **段间距**：「设置 → 阅读」新增段间距选项。

## 改进

- WebP 格式的漫画和插图解码速度提高一倍多，翻漫画更快。
- 点击阅读页顶部的状态栏不再误翻页。
- 程序异常退出时，详细信息会写入 `logs/kinnovel.log`，下次启动时会提示一次。

## 安装

下载 `KinNovel-v1.3.0.zip`，把其中 `KinNovel` 文件夹里的全部内容复制到 Kindle 的 `extensions/kinnovel/`，然后在 KUAL 中打开 KinNovel。升级时直接覆盖即可，配置、进度、书签和缓存都会保留。

注：书架编辑（加入、移出、删除文件夹）会写回云端书架。由于轻书架服务器维护期间无法实际验证，如遇问题请提交 Issue。

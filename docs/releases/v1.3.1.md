## 改进

- **插图与正文混排**：除了每卷开头的封面仍然占满一页，彩页和正文插图改为按图片的实际比例显示，最高约占屏幕的六成，和前后的文字排在同一页。横版彩页只占半页左右，两张可以排在一起。替代生僻字的小图按原始大小显示，不再放大成一整页。
- **继续阅读卡片显示封面**：书架顶部的「继续阅读」卡片左侧会显示这本书的封面；不知道封面时用第一章的卷首图。
- **界面更简洁**：去掉了书架、书签、搜索等页面上的操作提示文字，操作说明统一写在 README 的「使用」一节。
- 离线时，插图如果只缓存过其它尺寸，也会直接显示，不再提示未缓存。

## 安装

下载 `KinNovel-v1.3.1.zip`，把其中 `KinNovel` 文件夹里的全部内容复制到 Kindle 的 `extensions/kinnovel/`，直接覆盖即可，配置、进度、书签和缓存都会保留。

注：插图的显示尺寸变了，已缓存的插图在联网时会按新尺寸重新下载一次。

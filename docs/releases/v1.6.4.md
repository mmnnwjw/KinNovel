## 改进

- **续读更快**：打开有缓存的章节时，读取和解析不再排在网络请求后面；先排到上次阅读的位置就显示正文，其余页面在空闲时继续排版。
- **返回书架更轻快**：短时间内从阅读页返回时直接复用书架，书目资料也会暂存，不再每次扫描全部章节缓存、重复请求同一批书。
- **大原图可继续尝试**：全屏查看图片时，超过默认解码额度会显示「仍要加载」。选择后只为这张图片提高额度，仍保留大小上限；大图可能因内存不足而无法加载。预览或原图加载失败时会显示原因，并提供重新加载入口。

## 修复

- 章节 HTML 嵌套过深、评论回复异常互相引用时，程序不再因无限递归而退出。
- 章节、字体和图片缓存损坏后可以重新获取；设置、进度等本机数据保存得更稳妥。
- 应用内更新增加恢复机制，替换文件中途失败或断电后，下次启动会恢复；下载地址也能避开更新服务器残留的旧安装包缓存。
- 修复部分登录过期和 HTTP 响应处理问题，改善连接复用、后台任务调度与按下反馈。
- 主机预览可以加载 TTC 字体集，修复部分 Windows 环境下的字体加载失败。

此前的基础修复、书架和续读优化已在 Kindle Paperwhite 5 测试副本上验证；本次图片交互通过主机测试和多尺寸预览验证。

## 安装

可以在「我的 → 关于」或 KUAL「KinNovel 工具箱 → 检查更新」里直接更新。

手动安装：下载 `KinNovel-v1.6.4.zip`，把其中 `KinNovel` 文件夹里的全部内容复制到 Kindle 的 `extensions/kinnovel/`，直接覆盖即可，账号、设置、进度、书签和缓存都会保留。

## 新功能

- **应用内更新**：启动时发现新版本会在书架上弹一次提示（设置 → 内容 →「自动检查更新」开着时；每个版本只提示一次）。「查看更新」列出从当前版本到最新版之间每个版本的改动，「下载并安装」装好后点「立即重启」即可，账号、设置、进度、书签和缓存都保留。也可以随时在「我的 → 关于」里检查和更新。
- **KUAL 工具箱**：KUAL 里新增「KinNovel 工具箱」菜单，包含「检查更新」和「卸载 KinNovel」（确认后删除整个程序文件夹，服务器上的书架和进度不受影响）。
- **国内网络更新**：版本信息和安装包都会经 GitHub 加速镜像获取，连不上 GitHub 也能更新；下载的安装包都会校验 SHA-256，太慢的下载源会自动换下一个。

## 修复

- **符号方框**：正文和界面里系统字体没有的符号（例如 ♡ ♢ ♤ ♧ ✿ ✦ 〜）不再显示为方框，改用内置的补充字体（取自霞鹜新晰黑屏幕阅读版）显示。
- **「我的」页错位**：账号信息加载完时下面的列表不再往下跳，不会再点「退出」却点到「关于」。

在 Kindle Paperwhite 5 上测试过。

## 安装

从 1.6.2 起可以在「我的 → 关于」或 KUAL「KinNovel 工具箱 → 检查更新」里直接更新。1.6.1 及更早的版本需要手动安装这一次：下载 `KinNovel-v1.6.2.zip`，把其中 `KinNovel` 文件夹里的全部内容复制到 Kindle 的 `extensions/kinnovel/`，直接覆盖即可，账号、设置、进度、书签和缓存都会保留。

卸载：KUAL「KinNovel 工具箱 → 卸载 KinNovel」，或删除 `extensions/kinnovel/` 文件夹。

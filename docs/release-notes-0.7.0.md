图片加载性能重构，并修复一批阅读与交互稳定性问题。

### 图片加载

- **有界线程池取代“一图一进程”**：旧实现对每张插图新建一条 daemon 线程并 `fork` 一个 Python 进程，实测每次冷启动约 **1.07 秒 / 47 MB**；含多张插图的章节会同时拉起多个解释器。新实现统一走 2 个常驻 worker，按需下载、解码、缩放。
- **失败退避，修掉热循环**：图片下载/解码失败会进入指数退避并记录负缓存。此前失败会被当成成功，渲染下一帧立刻重试，形成“反复 fork 子进程 + 反复整屏刷新”的循环。
- **按用途请求服务端缩放图**：封面取 `height=512`；阅读插图按实际显示高度取 256/384/512/768/1024/1536/2048 桶；仅对带 `size=WxH` 的系统图床 URL 追加尺寸参数，与 Web 端行为一致。
- **解码一次到显示尺寸**：下载后按目标尺寸缩放并转为灰度 JPEG 落盘（封面约 55 KB），不再保存全尺寸 PNG，再次显示直接命中缓存（二次解码约 0.01 秒）。
- **内存按字节预算淘汰**：图片内存缓存改为 48 MB 字节预算 + 条目上限的双重 LRU；封面缩放结果单独缓存，不再每次渲染重跑 LANCZOS。
- **只预取当前页与后两页**：不再对整章插图一次性预取；插图到达后只刷新该插图所在矩形，不再触发整屏重绘。
- **书架不再预取自己不渲染的封面**。

### 稳定性

- **异步回调统一切回输入线程**：新增 UI 回调队列，输入循环以 50 ms 超时轮询并在主线程排空；修复工作线程并发修改页面 `STATE`、并发渲染的竞态。
- **修复插图状态泄漏**：下载期间离开阅读页不再让 URL 永久停留在 pending，插图不会永久显示 `[图片]`。
- **插图排版按真实宽高比**预留高度，减少正文与图片之间的空白。
- **章节目录空白行不可点击**；章节导航兼容非连续 `SortNum`。
- **书籍详情切书**不再渲染/操作上一本书的数据，章节预热使用正确的 `book_id`。
- **账号自动登录**在登录中离开页面后不再永久卡在“正在登录…”。
- **损坏的图片缓存文件**会被删除并重新下载，不再“粘住”。
- **退出更快更干净**：图片线程改为 daemon 线程池，退出不再等待下载完成；实机 `SIGTERM` 后约 3 秒退出并恢复原屏。

### 平台

- 修正经典 `mxcfb` 的 `mxcfb_rect` 字段顺序为 `top, left`，与 FBInk / Kindle 内核一致，为后续局部刷新铺路。
- 修正 framebuffer 整行写入快路径判断，避免行 stride 与屏宽不一致时误用。

### 测试

- Kindle 实机（Python 3.14）运行 **101 项单元测试全部通过**（1 项跳过）。
- 新增 `tests/test_images.py`：尺寸变体、并发去重、失败退避、损坏缓存恢复、真实 HTTP 下载缩放。
- 新增设备工具：`tools/live_image_bench.py`（低请求频率在线基准）、`tools/fb_grab.py`（帧缓冲截图）、`tools/device_boot_test.sh`（启动/退出/恢复验证）。

## 安装

1. 下载 `KinNovel-v0.7.0.zip`。
2. 解压后把 `KinNovel` 目录复制到 `/mnt/us/extensions/kinnovel`。
3. 在 `/mnt/us/extensions/kinnovel/bin/config.json` 中填写 `account_email` 和 `account_password`。
4. 从 KUAL 进入 `KinNovel` 并启动。

完整配置和排障说明见 README.md。

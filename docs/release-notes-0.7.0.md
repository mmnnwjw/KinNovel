图片加载性能重构，并修复一批阅读与交互稳定性问题。

### 变更

- **图片管线重构**：用 2 个常驻 worker 取代“每张图一条线程 + 一个 Python 子进程”，消除每张插图约 1.07 秒的解释器冷启动与 47MB 峰值内存。
- **失败退避**：图片下载/解码失败进入 2s、4s、8s… 指数退避并记录负缓存，修掉失败被当成成功后“反复 fork + 反复全屏刷新”的热循环。
- **按用途请求缩放图**：封面固定 `height=512`，正文插图按显示高度取 256–2048 分档；仅对带 `size=WxH` 的系统图床 URL 追加尺寸参数，与 Web 端一致。
- **解码一次到显示尺寸**：下载后按目标尺寸缩放并转灰度 JPEG 落盘（封面约 55KB），不再保存全尺寸 PNG，二次显示直接命中缓存（约 0.01 秒）。
- **内存按字节预算淘汰**：图片内存缓存改为 48MB 字节预算 + 条目上限双重 LRU，封面缩放结果单独缓存，不再每次渲染重跑 LANCZOS。
- **按页窗口预取**：只预取当前页与后两页插图，插图到达仅刷新所在矩形，不再整屏重绘；书架不再预取自己不渲染的封面。

### 修复

- **异步回调线程**：新增 UI 回调队列，异步回调统一切回输入线程执行，修复工作线程并发修改页面状态与渲染的竞态。
- **插图占位**：下载期间离开阅读页不再让 URL 永久 pending，插图不会一直显示 `[图片]`。
- **插图排版**：按真实宽高比预留高度，减少正文与插图之间的空白。
- **章节目录**：空白行不再可点击；章节导航兼容非连续 `SortNum`。
- **书籍详情**：切书不再显示/操作上一本的数据，章节预热使用正确的 `book_id`。
- **账号登录**：自动登录期间离开页面不再永久卡在“正在登录…”。
- **缓存自愈**：损坏的图片缓存文件会被删除并重新下载，不再“粘住”。
- **退出速度**：图片线程改为 daemon 线程池，退出不再等待下载完成，实机约 3 秒干净退出并恢复原屏。
- **经典 mxcfb 区域**：`mxcfb_rect` 字段顺序修正为 `top, left`，与 FBInk / Kindle 内核一致。
- **framebuffer 写入**：修正整行写入快路径对 stride 的判断，避免行距与屏宽不一致时误用。

## 安装

1. 下载 `KinNovel-v0.7.0.zip`。
2. 解压后把 `KinNovel` 目录复制到 `/mnt/us/extensions/kinnovel`。
3. 在 `/mnt/us/extensions/kinnovel/bin/config.json` 中填写 `account_email` 和 `account_password`。
4. 从 KUAL 进入 `KinNovel` 并启动。

完整配置和排障说明见 README.md。

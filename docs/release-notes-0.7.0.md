图片加载性能重构，并修复一批阅读与交互稳定性问题。

### 变更

- **插图更快**：重新设计插图的下载与缓存方式，减少等待时间和内存占用。
- **失败自愈**：插图下载失败会短暂退避后自动重试，不再反复重试并反复刷新屏幕。
- **按用途取图**：封面和正文插图请求合适尺寸的服务端缩放图，减少流量与等待。
- **缓存更省内存**：图片缓存按内存占用淘汰，并复用已缩放的插图。
- **预取更克制**：只预取当前页附近的插图，插图到达只刷新该插图区域。
- **显示细节**：修正部分机型刷新区域的坐标与写入处理。

### 修复

- **稳定性**：修复阅读页在后台线程更新界面导致的竞态。
- **插图占位**：下载期间离开阅读页后，插图不再永久停留在占位状态。
- **排版**：插图按真实比例预留高度，减少正文与插图之间的空白。
- **章节目录与跳转**：空白行不再可点击，章节跳转更准确。
- **书籍详情**：切换书籍不再短暂显示上一本内容。
- **账号登录**：登录过程中离开页面不再一直停在登录状态。
- **缓存恢复**：损坏的图片缓存会自动重新下载。
- **退出更快**：退出不再等待图片下载完成。

## 安装

1. 下载 `KinNovel-v0.7.0.zip`。
2. 解压后把 `KinNovel` 目录复制到 `/mnt/us/extensions/kinnovel`。
3. 在 `/mnt/us/extensions/kinnovel/bin/config.json` 中填写 `account_email` 和 `account_password`。
4. 从 KUAL 进入 `KinNovel` 并启动。

完整配置和排障说明见 README.md。
